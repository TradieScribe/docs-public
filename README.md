## 🏗️ Building Documentation Locally

This documentation is written in Markdown and can be viewed with any Markdown viewer or documentation generator.

### Using MkDocs (Recommended)

```bash
# Install MkDocs
pip install mkdocs mkdocs-material

# Serve documentation locally
mkdocs serve

# Build static site
mkdocs build
```

### Using Docusaurus

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

### Using Plain Markdown

Simply open the `.md` files in any Markdown viewer or text editor.
